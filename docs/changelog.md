## 2026-07-28

### 追加
- **画面下部にステータスバーを追加**（voice-generator から移植）— CPU / RAM / GPU / VRAM の使用状況を 1 秒ごとに表示します。
  - CPU・RAM は Electron メインプロセスの `node:os`、GPU・VRAM は `nvidia-smi` から取得し、IPC（`system:resources`）でレンダラーへプッシュ。バックエンド（Python）が落ちていても動作します
  - NVIDIA GPU が見つからない場合は GPU / VRAM の表示を省略。ブラウザ実行時（`window.__DESKTOP__` なし）はステータスバー自体を描画しません
  - 使用率が 65% を超えると黄、85% を超えると赤に変化
- **生成データの保存先フォルダを変更可能に**（`abfb2df`）— アプリ本体と生成データを分離できるようになりました。左パネルの「保存先フォルダ」から選択し、設定はプロジェクト直下の `app-config.json` に保存されます（既定は `data/`）。
  - 切り替えは選んだフォルダを読み込むだけで、ファイルの移動・コピー・削除は行いません
  - 生成中・待機中のジョブがあるときは変更できません（生成中の WAV が旧フォルダに取り残されるため）
  - 設定フォルダが使えない場合（ドライブ未接続など）は `data/` にフォールバックして起動します
  - モデル選択も `app-config.json` に移動（旧 `data/config.json` から自動移行）。保存先を変えても選択が維持されます
  - フォルダ選択ダイアログ／エクスプローラー起動のため、初めて IPC（`window.__DESKTOP__`）を導入
  - F12 スクリーンショットの保存先も設定に追従
  - API: `GET/POST /api/datadir`、`/api/health` に `data_dir` を追加
- 「保存先フォルダ」欄を開閉式に。折りたたみ時もフォルダ名を表示し、開閉状態は localStorage に保存されます

## 2026-05-30

### 追加
- **LLM / Stable Audio のオンオフトグル**（`3e37cb6`）— 上部バーの「Device: Cuda」表示を、常駐モデルの読込状態を示すピル型トグルに置き換え。必要なときだけ VRAM に載せられます（青=ロード済み／灰=オフ／点滅=読込中）
- **Qwen によるプロンプト補助とカードのタイトル**（`6524f37`）— ローカルの Qwen3.5-2B（`backend/suggest.py`）が、任意の言語のラフな入力を Stable Audio 向けの英語プロンプトに整形（`POST /api/suggest` +「推測」ボタン）。あわせて各ジョブに短いタイトルを付け、カードの見出しに表示。カードに生成モデル名も表示
- **オーディオプレーヤーのループ再生**（`29ee2df`）
- **EN/JA の言語切り替え**（`9f2cd1c`）— 軽量な i18n レイヤ（`i18n.jsx`）と上部バーの言語ドロップダウン。選択は localStorage に保存。あわせて `stable-audio-3-small-music` を選択肢に追加
- **音量スライダー**（`02dc0b0`）— ミュートのオン／オフだけだったところを、実際に音量を調整できるスライダーに変更
- **モデル切り替え（medium / small-sfx）**（`01fc23d`）— 要求されたモデルをロードし、別モデルが載っていれば解放。t5gemma テキストエンコーダは 1 つを共有。選択は永続化され、各ジョブにも使用モデルを記録
